Connectors

Connectors let the AI use other apps and tools, like your notes, files or GitHub. They use the Model Context Protocol, the open standard used by Claude, ChatGPT and other assistants, so thousands of existing connectors work here. The AI asks before it uses a tool unless you choose Always allow.

Connectors need a model that can use tools, such as qwen3:8b (install it with ollama pull qwen3:8b).
