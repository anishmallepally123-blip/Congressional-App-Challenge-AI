Setup

Get started in four steps

No installers and no admin rights. The first start downloads what the app needs, so allow a few minutes and a few gigabytes.

  1. Download and unzip

    Click Download the app to get LocalAIChat.zip, then unzip it. On Windows, right-click the zip and choose Extract All (don’t run it from inside the zip).

  2. Double-click to start

    Open the Local AI Chat folder and double-click Start Local AI Chat - Windows or Start Local AI Chat - Mac. If Windows warns you, click More info then Run anyway. On a Mac, go to System Settings › Privacy & Security and click Open Anyway (on macOS 14 or older, right-click the file and choose Open).

  3. Let it set itself up

    The first time, the app downloads its own copy of Python and the Ollama AI engine into its folder. Nothing is installed on the rest of your computer. On Windows, an Ollama window may pop up while it sets up; you can ignore or close it.

  4. Pick a model and chat

    Your browser opens the app at http://localhost:8000. It checks your computer’s memory and graphics card and recommends a model that fits (1.5 to 5 GB). Click Download, then start chatting.

Features

What it can do

Everything runs on your computer. Nothing is sent to the cloud.

Chat privately

Streaming answers, a “Think deeper” mode, chat history with search, formatted answers and code, and light and dark themes.

Picks a model that fits

Detects your memory and graphics card, recommends the best model, and locks ones too big for your computer.

Coding help

Bigger coding requests switch automatically to a coding model that fits your computer.

Folder organizer

The AI suggests how to tidy a messy folder. Nothing changes until you press Apply, and every change can be undone.

Connectors

Plug in other tools through the Model Context Protocol, with an approval card before any tool runs.

Use it on your phone

Chat from your phone over your home Wi-Fi after entering a pairing code, with the model still running on your computer.

Personalize it

Tell the AI about yourself, have it remember things, teach it with example answers, and save your own named assistants.

TinyGPT, our own model

A small language model we built and trained from scratch on Shakespeare. Download it in the app and watch it write in his style.

How it works

FAQ

Questions

Does it need the internet?

Only to download Ollama and an AI model the first time. After that it works completely offline.

What kind of computer do I need?

Any recent Windows or Mac computer. Models range from tiny ones that run on 8 GB laptops to large ones for powerful desktops, and the app picks one that fits.

What’s the difference between the download and “Try it in your browser”?

The browser demo runs a very small model inside your web browser so you can try chatting with nothing installed. The downloaded app runs bigger, smarter models with all the features: the organizer, shared files, connectors and phone access.

Where are my chats stored?

In your own browser and on your own computer. Nothing is uploaded anywhere.
