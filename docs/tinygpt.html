🧪 TinyGPT: an AI we built from scratch

Most AI models are made by big companies. TinyGPT is ours: we wrote the code and trained it on Shakespeare's plays, one letter at a time. It has about 800 thousand weights, while the models in the app have billions, so it can't answer questions. But it has learned to write in Shakespeare's style. It runs right here in your browser, on any device.

How it learned

It read Shakespeare over and over, each time guessing the next letter and nudging its weights when it guessed wrong.

Why it sounds odd

It only knows letters, not meanings, so it makes up words and names that look right. Lower Creativity makes it safer and more repetitive.
