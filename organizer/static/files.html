What sharing does

  • The AI can read the documents, slides, spreadsheets, PDFs and notes in a folder you share, so you can ask questions like "what did my history essay say about the New Deal?"
  • It also helps the organizer give clear names and folders to files like "Untitled 3.docx".
  • Everything stays on this computer. Your files are only read by the AI model running here.
  • Read-only. Answering questions never changes, moves or deletes a file.
  • Files that look private (passwords, keys) are never read. Stop sharing any time and the AI forgets that folder.
